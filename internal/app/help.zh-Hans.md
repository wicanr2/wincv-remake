# WinCV 使用说明

按 `Esc` 返回文件列表。本说明也可以滚动：`↑` `↓` `PgUp` `PgDn`。

最上面那一行是菜单栏。按 `F9` 展开，`←` `→` 切换分类，`↑` `↓` 选择项目，
`Enter` 执行。每一行右边都写着对应的按键，记住之后就不用再打开菜单。

## 文件列表

| 按键 | 操作 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移动光标 |
| Enter | 进入目录；文件上则是查看 |
| BackSpace | 返回上一层目录 |
| Space | 标记，光标移到下一格 |
| T / Alt-T / U | 标记所有文件 / 连目录一起标 / 取消所有标记 |
| S | 切换排序方式 |
| P | 更改路径 |
| Alt-D | 开关左侧磁盘窗格（Tab 切换焦点） |
| Alt-P | 开关底部预览窗格 |

光标停在压缩包上按 `Enter` 就当目录进入，里面的文件照样可以查看、可以解出来。
支持 ZIP、RAR、7Z、TAR、GZ、BZ2、LZH、ARJ、CAB、ARC、ACE、`.Z`。

## 对文件的操作

| 按键 | 操作 |
|---|---|
| C M R D | 复制 / 移动 / 重命名 / 删除 |
| Del | 彻底删除（先填 0 再删） |
| Alt-C | 比对两个标记的文件 |
| Z / Alt-Z | 解压 / 制作压缩包 |
| W | 查找 文件名 / 字符串 / 备注 |
| Alt-E | 备注（写入该目录的 dir.doc） |
| O / G | 用系统默认程序打开 / 运行 |

MD5 与 SFV 在菜单的“工具”里。

## 查看文件

按 `Enter` 查看，`Esc` 返回列表。

| 模式 | 进入方式 | 说明 |
|---|---|---|
| 文本 | Enter | 自动判断 Big5 / GB / UTF-8 / SJIS，识别 ANSI 色码 |
| 16 进制 | 可执行文件自动进入 | |
| 图片 | 图片文件上按 Enter | + - 缩放、方向键平移 |
| 缩略图列表 | 5 | 整个目录的图片一次看完 |
| markdown | .md 文件 | 标题、列表、表格、内嵌图片 |
| 编辑器 | E | PE2 式区块编辑，F6 查找替换 |

查看文本文件时 `/` 搜索、`n` 找下一个。

PDF 取出的是**文本与图片**，不是版面。PDF 描述的是“把这个字放在这个
坐标”，没有段落也没有分栏的概念，所以分栏排版的论文会变成左右两栏交错，
图片放在每一页的末尾（PDF 没有交代图片该画在哪一段旁边）。

## 网络浏览

按 `F2` 输入地址。`gopher://` 与 `http://` `https://` 都可以，
不写协议时按 gopher 处理。

| 按键 | 操作 |
|---|---|
| ↑ ↓ Tab | 在链接之间移动；没有链接的页面就是滚动 |
| Enter | 打开光标所在的链接 |
| BackSpace | 上一页 |
| F2 | 输入新地址 |
| Esc | 返回文件列表 |

网页只取文字、链接与图片，样式表与脚本一律丢弃，排出来的效果和 gopher 菜单
一样。**对外连接只在你自己输入地址、或按 `Enter` 跟随链接跳转时才会发生**，
程序不会自己连接任何地方。

## 显示

| 按键 | 操作 |
|---|---|
| Ctrl-+ Ctrl-- Ctrl-0 | 切换字号（8×15 → 10×18 → 12×24） |
| Alt-+ Alt-- Alt-0 | 缩放倍率，每次 0.1；Alt-0 恢复到 1.0 |
| F8 | 切换中英文显示 |
| F11 | 全屏 |
| F1 | 本说明 |
| F9 | 菜单 |

菜单这一层可以用**与内容不同的字体**：`F9` → 设置 → 菜单字号，
或启动时加 `-menu-font <字体文件> -menu-size <像素>` 用一份 TTF。
内容要的是与原版逐像素对齐的点阵字，菜单只是界面——在高分辨率屏幕上
大一号反而更容易辨认，两者硬绑在一起就只能二选一。

字号切换的是**点阵字本身**，字形会重新设计、细节更多；缩放倍率则是连续的，
每次 0.1，可以微调到刚好填满窗口。

缩放倍率不会单纯把字模硬拉大，而是先挑一个尺寸相近的原生点阵字号——
原版自带的三种（8×15 / 10×18 / 12×24）之间的比例正好是 1.19 与 1.56，
所以 1.2、1.5、1.6 这几档刚好落在原生字模上，每个像素都是当年设计
出来的。其余倍率仍会有粗细不均，但比直接把 8×15 拉大轻微得多
（1.4 倍是把 10×18 拉大 1.18 倍）。完整对照表见 docs/ui/keymap.md。

全角中文在 8×15 以外的字号改用系统的矢量字体绘制（抗锯齿）——倚天(ETEN)
只有 15 点那一份字库，硬缩放会整片锯齿。要全部用倚天(ETEN)缩放，启动时加 `-bitmap-cjk`。

窗口拉大时内容会**变多**而不是变大——格子大小固定，多出来的空间就是多出几格。
要固定格数请用菜单的“设置 → 窗口大小”。

## 查看图片与 PDF 整页

`+` / `-` 放大缩小，`1` 回到原始尺寸，`F` 在“缩放到窗口”与指定倍率之间切换，
方向键平移。PDF 按 `V` 查看整页时，放大是用更高的分辨率**重新绘制**，不是把图片拉大——
所以放大之后能看到更多细节。

PDF 的整页模式下 `PgUp` / `PgDn`(或 `Enter` / `BackSpace`)是**翻页**,
不是切换到目录里的下一张图片,而且翻页后放大倍率保持不变。按 `Esc` 退回时
看到的是同一页的文本。

## 主文件名栏的宽度

列表默认是原版的 8.3 版面。`Ctrl-→` / `Ctrl-←` 把主文件名栏加宽或缩窄一格，
或按住鼠标左键在列表上左右拖动；长文件名就直接显示在列表里。会记住设置。

## 鼠标

单击列表移动光标，双击打开；网页上的链接单击就跳转过去。点最上面那一行
展开菜单，点项目执行，点别处收起。滚轮滚动；按住方向键会自动重复。

## Android

底部三行：最上面一行是当前模式的操作，下面两行是按键——方向键排成十字，
Esc 与 Enter 在两端，PgUp / PgDn / Home / End 在旁边。接上实体键盘（dock、
蓝牙）时按键与桌面版相同。

## 记住每个文件看到哪里

查看、编辑、HEX、markdown 离开再回来，会回到上次的位置（编辑器连光标
位置都记）。每个文件各记一条，最多 500 个，满了就丢弃最久未用的。

## 记住上次的位置

关闭时会记下你在哪个目录、光标停在哪个文件、开着哪份文档与滚动到第几行，
下次打开时回到同一个地方。字号、缩放倍率与窗口格数也一起带回去。

标记、搜索结果与浏览历史不记——那些是这一次的工作内容。
启动时在命令行指定目录的话以命令行为准。

## 关于本程序

这是 1999–2011 年台湾共享软件 **WinCV 0.52**（CView for Windows，
原作者 Lcc Wizard）的重制版，用 Go 重写，源代码公开。
原版的著作权属于原作者；重写是为了保存这份软件，不是取得原版的权利。

`F9` → 说明 → 关于，有版本与授权信息。
