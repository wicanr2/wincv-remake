# WinCV ヘルプ

`Esc` でファイル一覧に戻ります。このヘルプもスクロールできます:`↑` `↓` `PgUp` `PgDn`。

画面の最上段はメニューバーです。`F9` で開き、`←` `→` でカテゴリを切り替え、
`↑` `↓` で項目を選び、`Enter` で実行します。各項目の右側には対応するキーが
表示されており、覚えてしまえばメニューを開く必要はなくなります。

## ファイル一覧

| キー | 動作 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | カーソル移動 |
| Enter | ディレクトリへ移動、ファイルなら表示 |
| BackSpace | 上位ディレクトリへ |
| Space | マーク、カーソルは1つ下へ |
| T / Alt-T / U | 全ファイルをマーク／ディレクトリも含めてマーク／マーク解除 |
| S | ソート順切替 |
| P | パス変更 |
| Alt-D | 左のドライブペインの表示切替(Tab でフォーカス移動) |
| Alt-P | 下のプレビューペインの表示切替 |

カーソルを書庫の上に置いて `Enter` を押すと、ディレクトリと同じように中へ
入れます。中のファイルはそのまま表示・解凍できます。対応形式:ZIP、RAR、
7Z、TAR、GZ、BZ2、LZH、ARJ、CAB、ARC、ACE、`.Z`。

## ファイルに対する操作

| キー | 動作 |
|---|---|
| C M R D | コピー／移動／リネーム／削除 |
| Del | 完全削除(0 で上書き後に削除) |
| Alt-C | マークした2ファイルを比較 |
| Z / Alt-Z | 解凍／書庫作成 |
| W | ファイル名／文字列／コメント検索 |
| Alt-E | コメント(そのディレクトリの dir.doc に書込み) |
| O / G | 既定アプリで開く／実行 |

MD5 と SFV はメニューの「ツール」にあります。

## ファイルの表示

`Enter` で表示、`Esc` で一覧に戻ります。

| モード | 入り方 | 説明 |
|---|---|---|
| テキスト | Enter | Big5／GB／UTF-8／SJIS を自動判別、ANSI カラーコード対応 |
| 16進数 | 実行ファイルは自動的に | |
| 画像 | 画像ファイル上で Enter | `+` `-` で拡大縮小、矢印キーで移動 |
| サムネイル一覧 | 5 | ディレクトリ内の画像を一括表示 |
| markdown | .md ファイル | 見出し・リスト・表・埋込み画像 |
| エディタ | E | PE2 方式のブロック編集、F6 で検索置換 |

テキスト表示中は `/` で検索、`n` で次を検索します。

PDF から取り出せるのは**文字と画像**であり、レイアウトではありません。PDF が
記述しているのは「この文字をこの座標に置く」ということだけで、段落や段組み
という概念自体がありません。そのため段組みの論文は左右の列が入り交じった
状態になり、画像は各ページの末尾にまとめて表示されます(PDF はどの段落の
そばに画像を置くべきかを記録していないため)。

## ウェブ閲覧

`F2` でアドレスを入力します。`gopher://` のほか `http://` `https://` も
使えます。プロトコルを省略した場合は gopher として扱われます。

| キー | 動作 |
|---|---|
| ↑ ↓ Tab | リンク間を移動、リンクのないページはスクロール |
| Enter | カーソル位置のリンクを開く |
| BackSpace | 前のページへ |
| F2 | 新しいアドレスを入力 |
| Esc | ファイル一覧へ戻る |

ウェブページは文字・リンク・画像のみを取り出し、スタイルシートとスクリプト
はすべて破棄します。表示結果は gopher メニューと同じ見た目になります。
**外部への接続は、自分でアドレスを入力したとき、または `Enter` でリンクを
たどったときにのみ発生します**。プログラムが自動的にどこかへ接続することは
ありません。

## 表示

| キー | 動作 |
|---|---|
| Ctrl-+ Ctrl-- Ctrl-0 | フォントサイズ切替(8×15 → 10×18 → 12×24) |
| Alt-+ Alt-- Alt-0 | 拡大率、0.1 刻み。Alt-0 で 1.0 に戻る |
| F8 | 中国語／英語表示切替 |
| F11 | フルスクリーン |
| F1 | このヘルプ |
| F9 | メニュー |

メニュー層は**コンテンツとは別のフォント**を使えます:`F9` → 設定 →
メニューフォントサイズ、または起動時に `-menu-font <フォントファイル>
-menu-size <ピクセル>` を指定して TTF を使います。コンテンツに求められるのは
原版とピクセル単位で一致するビットマップフォントですが、メニューは単なる
インターフェースです——高解像度の画面では一段大きいほうがかえって見やすく、
両者を一体化してしまうとどちらかを犠牲にするしかなくなります。

フォントサイズを切り替えると**ビットマップフォント自体**が変わり、字形が
新たに設計し直されて細部の情報量が増えます。一方の拡大率は連続的な値で、
0.1 刻みで微調整でき、ウィンドウをちょうど埋めるところまで合わせられます。

拡大率は単純にグリフを引き伸ばすのではなく、まず目標に近いネイティブの
ビットマップフォントサイズを選びます。原版に付属する3種類(8×15／10×18／
12×24)の比率はちょうど 1.19 と 1.56 であるため、拡大率が 1.2、1.5、1.6 の
ときはネイティブのグリフにぴったり一致し、どのピクセルも当時設計された
そのままになります。それ以外の拡大率では線の太さにわずかな不均一が残り
ますが、8×15 を直接引き伸ばす場合よりはるかに軽微です(1.4 倍は実際には
10×18 を 1.18 倍に引き伸ばしているだけです)。全対応表は
`docs/ui/keymap.md` にあります。

8×15 以外のフォントサイズでは、全角の中国語文字はシステムのベクターフォント
で描画されます(アンチエイリアス処理付き)——倚天(ETEN)には 15 ポイントの
字庫しかなく、そのまま拡大すると全体がギザギザになるためです。すべてを
倚天の拡大描画にしたい場合は、起動時に `-bitmap-cjk` を指定してください。

ウィンドウを大きくするとコンテンツは**増える**のであって、大きくなるわけ
ではありません——セルのサイズは固定で、増えた分の空間はセル数の増加に
あてられます。セル数を固定したい場合はメニューの「設定 → ウィンドウ
サイズ」を使ってください。

## 画像表示と PDF ページ表示

`+` / `-` で拡大縮小、`1` で原寸に戻る、`F` で「ウィンドウに合わせる」と
指定倍率の切替、矢印キーで移動します。PDF を `V` でページ全体表示にして
いるとき、拡大は画像を引き伸ばすのではなく、より高い解像度で**再描画**
します——そのため拡大するほど細部まで見えるようになります。

PDF のページ全体表示では `PgUp` / `PgDn`(または `Enter` / `BackSpace`)が
**ページ送り**になります。ディレクトリ内の次の画像には移りません。拡大率は
そのまま引き継がれ、`Esc` で戻ると同じページのテキストが表示されます。

## ファイル名欄の幅

一覧は既定で原版の 8.3 形式のレイアウトになっています。`Ctrl-→` /
`Ctrl-←` でファイル名欄を1マスずつ広げる・狭めるか、マウスの左ボタンを
押したまま一覧上を左右にドラッグします。長いファイル名はそのまま一覧に
表示されます。この設定は記憶されます。

## マウス

一覧をクリックするとカーソルが移動し、ダブルクリックで開きます。ウェブ
ページ上のリンクはクリックだけで移動します。最上段をクリックするとメニュー
が開き、項目をクリックすると実行、それ以外の場所をクリックすると閉じます。
ホイールでスクロールし、矢印キーを押し続けると自動的に繰り返されます。

## Android

画面下部の3段:最上段はそのモードでの操作、下の2段はキーです——方向キーが
十字に配置され、`Esc` と `Enter` が両端に、`PgUp` / `PgDn` / `Home` /
`End` がそのわきに並びます。物理キーボード(ドックや Bluetooth)を接続した
場合は、デスクトップ版と同じキー操作になります。

## 各ファイルの表示位置の記憶

テキスト表示、編集、HEX 表示、markdown 表示から離れて戻ってくると、前回の
位置に復帰します(エディタではカーソル位置まで記憶します)。ファイルごとに
1件記憶し、最大 500 件まで。上限に達すると最も長く使われていないものから
破棄されます。

## 前回のセッションの記憶

終了時にはどのディレクトリにいたか、カーソルがどのファイルにあったか、
どの文書を開いていたか、何行目までスクロールしていたかが記憶され、次回
起動時に同じ場所へ戻ります。フォントサイズ、拡大率、ウィンドウのセル数も
一緒に引き継がれます。

マーク、検索結果、閲覧履歴は記憶されません——それらは今回限りの作業だから
です。起動時にコマンドラインでディレクトリを指定した場合はそちらが優先
されます。
