# WinCV 使用說明

按 `Esc` 回到檔案清單。這份說明也可以捲動:`↑` `↓` `PgUp` `PgDn`。

最上面那一列是選單列。按 `F9` 展開,`←` `→` 換分類,`↑` `↓` 選項目,
`Enter` 執行。每一列右邊都寫著對應的按鍵，記住之後就不必再開選單。

## 檔案清單

| 按鍵 | 動作 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移動游標 |
| Enter | 進入目錄；在檔案上是看檔 |
| BackSpace | 回上一層目錄 |
| Space | 標記，游標往下一格 |
| T / Alt-T / U | 標記所有檔案 / 連目錄一起標 / 解除所有標記 |
| S | 換排序方式 |
| P | 改變路徑 |
| Alt-D | 開關左側磁碟窗格（Tab 切換焦點） |
| Alt-P | 開關底部預視窗格 |

游標停在壓縮檔上按 `Enter` 就當目錄走進去，裡面的檔案照樣可以看、可以解出來。
支援 ZIP、RAR、7Z、TAR、GZ、BZ2、LZH、ARJ、CAB、ARC、ACE、`.Z`。

## 對檔案做的事

| 按鍵 | 動作 |
|---|---|
| C M R D | 拷貝 / 移動 / 更名 / 刪除 |
| Del | 徹底刪除（先填 0 再刪） |
| Alt-C | 比對兩個標記起來的檔案 |
| Z / Alt-Z | 解壓縮 / 製作壓縮檔 |
| W | 尋找 檔名 / 字串 / 註解 |
| Alt-E | 註解（寫進該目錄的 dir.doc） |
| O / G | 用系統預設程式開啟 / 執行 |

MD5 與 SFV 在選單的「工具」裡。

## 看檔案

按 `Enter` 看檔，`Esc` 回清單。

| 模式 | 進入方式 | 說明 |
|---|---|---|
| 文字 | Enter | 自動判讀 Big5 / GB / UTF-8 / SJIS，認得 ANSI 色碼 |
| 16 進位 | 執行檔自動進入 | |
| 圖片 | 圖檔上按 Enter | + - 縮放、方向鍵平移 |
| 縮圖列表 | 5 | 整個目錄的圖一次看 |
| markdown | .md 檔 | 標題、清單、表格、內嵌圖片 |
| 編輯器 | E | PE2 式區塊編輯，F6 尋找取代 |

看文字檔時 `/` 搜尋、`n` 找下一個。

PDF 取出的是**文字與圖片**,不是版面。PDF 描述的是「把這個字放在這個
座標」,沒有段落也沒有欄的概念,所以分欄的論文會變成左右欄交錯,
圖片放在每一頁的末尾(PDF 沒有交代圖畫在哪一段旁邊)。

## 網路瀏覽

按 `F2` 輸入位址。`gopher://` 與 `http://` `https://` 都可以，
不寫協定時當 gopher。

| 按鍵 | 動作 |
|---|---|
| ↑ ↓ Tab | 在連結之間移動；沒有連結的頁面就是捲動 |
| Enter | 開啟游標所在的連結 |
| BackSpace | 上一頁 |
| F2 | 輸入新位址 |
| Esc | 回檔案清單 |

網頁只取文字、連結與圖片，樣式表與腳本一律丟掉，排出來的東西和 gopher 選單
長得一樣。**連外只在你自己輸入位址、或按 `Enter` 跟著連結走的時候發生**，
程式不會自己連任何地方。

## 畫面

| 按鍵 | 動作 |
|---|---|
| Ctrl-+ Ctrl-- Ctrl-0 | 換字級（8×15 → 10×18 → 12×24） |
| Alt-+ Alt-- Alt-0 | 放大倍率，每次 0.1；Alt-0 回到 1.0 |
| F8 | 切換中英文顯示 |
| F11 | 全螢幕 |
| F1 | 這份說明 |
| F9 | 選單 |

選單那一層可以用**與內容不同的字**:`F9` → 設定 → 選單字級,
或啟動時加 `-menu-font <字型檔> -menu-size <像素>` 用一份 TTF。
內容要的是與原版逐像素對齊的點陣字,選單只是介面——在高解析度螢幕上
大一級反而好認,兩者硬綁在一起就得二選一。

字級換的是**點陣字本身**，字形會重新設計、細節更多；放大倍率則是連續的，
每次 0.1，可以微調到剛好填滿視窗。

放大倍率不會單純把字模硬拉大，而是先挑一個尺寸相近的原生點陣字級——
原版隨附的三種（8×15 / 10×18 / 12×24）之間的比例正好是 1.19 與 1.56，
所以 1.2、1.5、1.6 這幾格剛好落在原生字模上，每個像素都是當年設計
出來的。其餘的倍率仍會有粗細不勻，但比直接把 8×15 拉大輕微得多
（1.4 倍是把 10×18 拉大 1.18 倍）。完整的對照表在 docs/ui/keymap.md。

全形中文在 8×15 以外的字級改用系統的向量字型畫（反鋸齒）——倚天只有
15 點那一份字庫，硬縮放會整片鋸齒。要全部用倚天縮放，啟動時加 `-bitmap-cjk`。

視窗拉大時內容會**變多**而不是變大——格子大小固定，多出來的空間就是多幾格。
要固定格數請用選單的「設定 → 視窗大小」。

## 看圖與 PDF 整頁

`+` / `-` 放大縮小，`1` 回到原尺寸，`F` 在「縮放到視窗」與指定倍率之間切換，
方向鍵平移。PDF 按 `V` 看整頁時，放大是用更高的解析度**重畫**，不是把圖拉大——
所以放大之後看得到更多細節。

PDF 的整頁模式下 `PgUp` / `PgDn`(或 `Enter` / `BackSpace`)是**換頁**，
不是換目錄裡的下一張圖，而且換頁之後放大倍率不變。`Esc` 退回去時看到的
是同一頁的文字。

## 主檔名欄的寬度

清單預設是原版的 8.3 版面。`Ctrl-→` / `Ctrl-←` 把主檔名欄加寬或縮窄一格，
或按著滑鼠左鍵在清單上左右拖；長檔名就直接顯示在清單裡。會記住。

## 滑鼠

單擊清單移游標，雙擊開啟；網頁上的連結單擊就跟過去。點最上面那一列
展開選單，點項目執行，點別處收起。滾輪捲動；按住方向鍵會自動重複。

## Android

底部三列：最上面一列是這個模式的動作，底下兩列是按鍵——方向鍵排成十字，
Esc 與 Enter 在兩端，PgUp / PgDn / Home / End 在旁邊。接上實體鍵盤（dock、
藍牙）時按鍵與桌面版相同。

## 記住每個檔案看到哪

看檔、編輯、HEX、markdown 離開再回來，會回到上次的位置（編輯器連游標
都記）。每個檔案各記一筆，最多 500 個，滿了丟最久沒用的。

## 記住上次的位置

關掉時會記下你在哪個目錄、游標停在哪個檔、開著哪份文件與捲到第幾列,
下次開起來回到同一個地方。字級、放大倍率與視窗格數也一起帶回去。

標記、搜尋結果與瀏覽歷史不記——那些是這一次的工作。
啟動時在命令列指定目錄的話以命令列為準。

## 關於這個程式

這是 1999–2011 年台灣共享軟體 **WinCV 0.52**（CView for Windows，
原作者 Lcc Wizard）的重製版，用 Go 重寫，原始碼公開。
原版的著作權屬於原作者；重寫是為了保存這份軟體，不是取得原版的權利。

`F9` → 說明 → 關於，有版本與授權。
