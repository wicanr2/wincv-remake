WinCV Remake 版本演變:

[0;1;35m2026-08-20 [33mremake 0.1[0m

        把 WinCV 0.52 用 Go + Ebiten 重寫,Linux / Windows / macOS 三平台。
        原作 Lcc Wizard(林健總),原版最後更新 2011-11-24。

        ★ 檔案瀏覽器:目錄列表、游標、標記、排序、進出目錄、註解(dir.doc)。
        ★ 壓縮檔當目錄瀏覽:12 種格式全支援。LZH / .Z / CAB / ARJ / ARC / ACE
            六個解碼器是自己寫的,各自對參考實作逐檔比對 sha256 驗過。
        ★ 文字檢視:編碼判讀(Big5/GBK/SJIS/EUC-KR/UTF-8/UTF-16)、ANSI 色碼、
            換行、搜尋、語法上色(沿用原版的 keyword_*.cfg)。
        ★ PE2 式區塊編輯器:矩形與整列區塊、虛擬空白、undo、F6 尋找/取代。
        ★ 看圖與縮圖列表:12 種格式支援 11 種。
        ★ 英漢字典與 KK 音標。音標的自訂編碼已解出,轉成 IPA 顯示。
        ★ MD5 與 SFV(CRC32)檢驗、換行與編碼轉換、去 HTML/ANSI。
        ★ Alt-P 預視窗格、F1 選單、F8 中英文顯示、F11 全螢幕。
        ★ 視窗放大時內容跟著變多;Ctrl-+ / Ctrl-- 在原版隨附的三種點陣
            字型之間換字級(8x15 / 10x18 / 12x24)。
        ★ markdown 檢視:開 .md 直接排版,圖片(PNG/GIF/SVG)嵌在文件裡
            顯示,Enter 可以把圖放大。圖片只認文件目錄底下的相對路徑,
            不下載遠端圖片。
        ★ Android 版:APK 建得出來了(四個 ABI,minSdk 21),第一版是
            唯讀瀏覽器。原版字型是版權物不打包,先用系統字型頂著。
        ★ 觸控功能列,celldump 加 -touch 在桌面上也看得到。
        ★ Alt-+ / Alt-- 整數倍放大;F1 → 視窗大小 可以設欄列數。
        ★ UTF-8:倚天字庫是 Big5 索引的,Big5 以外的字(简体字、韓文、
            希臘文、多數符號)改用系統字型補;真的缺字會畫成空框,
            不會安靜地變成空白。

        註: 半形字模直接解析原版的 cvga.fon(8x15);全形中文原版是交給
            Windows 系統字型畫的,重製版改用倚天(ETEN)點陣字,16x15 的
            全形格與 8x15 的半形格剛好對齊。

        註: 29 個具名顏色的名稱與 RGB 都是從 WINCV.IMG 裡解出來的,不是重配的。
            檔案清單的副檔名配色另外量自原版畫面。

        註: 主畫面格點量測 —— 格子 8x16(字模 8x15 靠上對齊),欄起點 x=34,
            清單 18 列。原版的選單列與工具列是 Win32 控制項,重製版全部自繪。

        尚未實作: ACE 的 SOUND / PIC 子模式、CAB 的 LZX / Quantum、
            ARC 的方法 4 與 7、LHA 的 -lh1-、Photo CD 圖檔。
            共同的判準是沒有可比對的參考實作就不寫 —— 沒驗過的解碼器
            會安靜地解出看起來有內容、實際上是錯的檔案。

        ★ 左側磁碟窗格(Alt-D)、捲軸、清單與狀態列之間的分隔線。
            原版的磁碟窗格與捲軸是 Win32 控制項,重製版用格子做等價物。24 點的全形漢字(倚天光碟上是
            ETUNPACK 壓縮的),所以放大字級時全形字是從 16x15 縮放的。
