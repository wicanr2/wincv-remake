## 尚待實測的項目

1. `↑↓` `Home` `End` 的實際行為(等級 C)。
2. 主畫面 `Enter` 在壓縮檔上是「進入」還是「解壓縮」。
3. `Esc` 的語意 —— 原版是回上一層還是離開程式。這關係到
   `~/.claude/knowledge-base/retro-cht/esc-cancel-f10-quit-autosave/SKILL.md` 的處理原則。
4. `5` 的「改變檔案列表的方式」實際有幾種模式。
